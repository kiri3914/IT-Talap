# План сайта

**Режим: разработка без публикации.** Строим всё, ничего не выкладываем.
С готовым продуктом идём к hh за разрешением (условия API, см.
[sources/hh.md](sources/hh.md) §5) и дальше действуем по ответу.

Разработка для себя и команды не нарушает условия: п. 3.8 разрешает
использовать приложение для собственных нужд.

## Правила на время разработки

1. **Данные по вакансиям не попадают в git.** Репозиторий публичный —
   выгрузка в нём уже публикация. Выгрузка лежит в `web/public/data/`,
   каталог в `.gitignore`.
2. **Превью — только для команды**, не в открытый доступ.
3. **История вакансий в Python — временная эталонная реализация.** Core-слой
   (снапшоты, SCD2, события) по ТЗ §12.1 пишется руками в dbt. Когда он
   появится, выгрузка читает из него, а Python остаётся проверкой: обе
   реализации обязаны давать одинаковые цифры.

## Архитектура

Статическое приложение: React + TypeScript (Vite), данные — JSON, который
каждую ночь выгружает `scripts/export_app_data.py`. Своего сервера нет.
Тяжёлое (медианы, Каплан — Мейер, события) считается в Python заранее,
браузер только фильтрует и рисует.

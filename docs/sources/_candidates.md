## 2. Топ-15 кандидатов

1. **hh.ru / семейство HeadHunter** — единственная площадка из статей, у которой есть прямые локальные домены для KZ/UZ/KG, стабильный числовой ID вакансии и поле зарплаты.
2. **Habr Карьера** — чисто IT, вилки указываются почти всегда, стабильный ID в URL вакансии, много релокации/удалёнки для СНГ.
3. **Remote OK** — remote-only, вилки обязательны в листинге, публичный ID вакансии, доступна из Центральной Азии.
4. **We Work Remotely** — крупный remote-агрегатор с устойчивыми URL-слагами вакансий и IT-фокусом.
5. **Wellfound (ex-AngelList)** — стартап-вакансии почти всегда с вилкой и remote-опцией, стабильный ID.
6. **Relocate.me** — IT + релокация, целевая аудитория — кандидаты из СНГ, включая KZ.
7. **Getmatch** — IT-агрегатор, где вилка является обязательным атрибутом вакансии.
8. **Geekjob** — IT-only, компактный каталог с ID вакансии, много удалёнки для СНГ.
9. **Careerspace** — IT/digital, часть вакансий международные и с указанием вилки.
10. **Djinni** — СНГ-ориентированная площадка, где зарплатная вилка — обязательное поле.
11. **Remote.co** — remote IT-вакансии, простая структура листинга, пригодна для парсинга.
12. **Indeed** — глобальный агрегатор с локальными доменами, потенциально покрывает KZ (нужна проверка).
13. **Glassdoor** — международный, содержит оценку/диапазон зарплат, но IT не выделен.
14. **Tproger Jobs** — IT-медиа с собственной доской, RU, но простая структура и IT-фокус.
15. **InGameJob** — узкая ниша (геймдев), СНГ-покрытие, вилки встречаются; кандидат «на потом».

## 4. Отброшены и почему

- **LinkedIn** — запрет скрейпинга в ToS (жёсткое условие проекта). Упоминался во всех 4 статьях.
- **Upwork, Toptal, Contra** — фриланс-биржи: проекты/заказы, а не вакансии.
- **GitHub** — не доска вакансий, в статье фигурирует как канал поиска людей, а не вакансий.
- **Hired, FlexJobs, Turing** — платный/закрытый доступ к листингам, публичного каталога с ID нет.
- **Корпоративные карьерные страницы (Яндекс, Сбер, Ozon, VK, МТС, Kaspersky и др.)** — один работодатель,
  RU-only, нет покрытия KZ/UZ/KG; вилки почти никогда не публикуются.
- **Facebook- и ВК-группы** — нет структуры вакансии, нет ID, нет вилок, требуют авторизации.
- **Конференции (HighLoad++, CodeFest, ProductSense и др.)** — офлайн-мероприятия, не источники вакансий.
- **Idealist, Jora, Layboard, CrunchBoard** — либо не IT, либо география вне зоны интереса, либо
  слабая структурированность данных.
- **SuperJob, Rabota.ru, БУДУ, vc.ru/job** — RU-only и без IT-фокуса; низкий приоритет относительно hh.

## 5. Ограничения этого документа

- Всё выше — только то, что реально упомянуто в четырёх статьях. Ни один сайт не проверялся вживую.
- Наличие зарплатных вилок и стабильных ID указано как *ожидание* по природе площадки, а не как проверенный факт.
- Пробел: статьи не покрывают локальные KZ/UZ/KG-площадки. Для полноты списка нужен отдельный поиск
  по местным источникам (hh.kz, Enbek.kz, HeadHunter UZ, Job.kg, локальные IT-сообщества).

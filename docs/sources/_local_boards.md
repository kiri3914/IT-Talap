## 2. Ключевые находки

### 2.1. Узбекистан остаётся без пригодного источника — главная дыра

Самая крупная и живая узбекская площадка **ishkop.uz** (676 IT-вакансий, ~65% с зарплатами, свежие даты) закрыта с двух сторон:

1. **ToS, дословно:**
   > «Не производить поиск, сбор и систематизацию данных других Пользователей, в т.ч. посредством использования компьютерных программ («ботов»).»
2. **robots.txt** запрещает `/jobdesc` — а это ровно тот эндпоинт, по которому открывается карточка вакансии (`/jobdesc?id=4785946`). Плюс `GPTBot` запрещён целиком (`Disallow: /`).

По правилу проекта прямой запрет в ToS = не подключаем. Обсуждению не подлежит.

Запасной вариант **ish.uz** технически открыт (robots.txt запрещает только личные кабинеты, компании и резюме — вакансии свободны), но отдаёт «No data» без исполнения JS. Нужен headless-браузер, объём и живость **не проверены**.

### 2.2. Хабр Карьера регион не покрывает

Фильтр по локации существует и работает: URL вида `career.habr.com/vacancies/java_developer/tashkent-175535` открывается корректно и возвращает «Поиск не дал результатов». На всём сайте 1 253 вакансии — это площадка про российский рынок. **Не берём.**

### 2.3. rabota.kz — самая чистая с правовой стороны

Единственная площадка, где удалось прочитать пользовательское соглашение целиком (`rabota.kz/pages/terms`) и где **никакого пункта о запрете автоматического сбора, парсинга, ботов или копирования данных не обнаружено**. robots.txt запрещает только личные разделы и пагинацию с `?after=`, а карточки `/job/list/<hex-id>` открыты. Зарплаты примерно у 70–75%.

### 2.4. enbek.kz — самый большой объём, но robots двусмысленный

Государственный портал, 95 057 вакансий, из них 991 в категории «IT и телекоммуникации», ~50% с зарплатой, стабильный числовой ID (`/ru/vacancy/<slug>~5940534`).

Тонкость: в robots.txt есть `Disallow: /*/search/*`, под который **подпадает страница листинга** `/ru/search/vacancy`. Карточки вакансий при этом не запрещены. Обход листинга придётся строить через `sitemap.xml` либо согласовать отдельно — как гос. портал с бесплатным публичным доступом enbek скорее всего не против, но на глаз это решать нельзя.

## 3. Что осталось непроверенным

- ToS у enbek.kz, newjob.kg, astanahub.com, djinni.co (у последнего `/terms/` отдаёт 404 — реальный путь не нашли).
- Число именно IT-вакансий на rabota.kz: поисковый URL с фильтром специализации подобрать не удалось (`/job/search?specializations=1` → 404).
- zarplata.kz, joblab.kz, jobs.kg, qyzmet.kz, olx.kz, lalafo.kg, workland.kg — обнаружены, но не проверены.
- Наличие публичных API не подтверждено **ни у одной** площадки. Везде исходим из HTML.
- Rate limit'ы нигде не замерялись — нагрузочных запросов не делали.
- job.kg (по поисковой выдаче — площадка №1 в Бишкеке) не резолвится по DNS. Возможно, временно; стоит перепроверить позже.

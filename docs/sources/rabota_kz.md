## 1. Вердикт — ПЕРЕСМОТРЕН 2026-09-12

**Рекомендация:** низкий приоритет. Не Фаза 1, не Фаза 2.

**Причина:** площадка не про IT. Из 7 296 вакансий в sitemap IT-похожих — **141 (2%)**.

Проверено разбором `https://rabota.kz/sitemap/job.xml` (7 296 URL вида
`/job/<Город>/<Профессия>/<24-hex-id>` — профессия и город прямо в ссылке):

| Топ профессий на площадке | Вакансий |
|---|---|
| Менеджер по продажам | 497 |
| Менеджер | 289 |
| Бухгалтер | 273 |
| Администратор | 243 |
| Водитель | 183 |
| **Программист** | **16** |
| **Системный администратор** | **4** |

Против 2 026 IT-вакансий на hh по Казахстану это плюс ~7% охвата,
преимущественно 1С и дизайнеры.

### Что было оценено неверно в первой версии

- «7 287–7 664 вакансий» — это **все** вакансии, а не IT. В разделе 2 честно
  стояло «Всего IT-вакансий: не проверено», но вердикт был построен на общем числе.
- «Зарплата у 70–75%» мерилась по общему листингу, где преобладает розница —
  там вилку указывают почти всегда. Для IT-подмножества доля не проверялась.

**Урок:** не сравнивать общий объём площадки с профильным объёмом другой.
Считать целевое подмножество до того, как ставить приоритет.

### Что при этом остаётся верным

ToS чист, robots.txt разрешает карточки, sitemap отдаёт полный список
без пагинации (которая как раз запрещена в robots), ID стабильный —
24-символьный hex. Если понадобится общая статистика по рынку труда,
а не только IT, источник хороший. Для нашей задачи — нет.

## 1.1. Технические детали (пригодятся, если вернёмся)

```
Sitemap: https://rabota.kz/sitemap/index.xml
  ├── job.xml      7 296 URL, lastmod у каждой
  ├── company.xml
  ├── cv.xml       (резюме — не трогаем)
  └── main-city.xml
```

robots.txt запрещает `/job/*?after=` — то есть **пагинацию листинга**.
Легальный путь перечисления один: sitemap. Он же даёт `lastmod`,
по которому видно обновление без скачивания карточки.

Города: Алматы 3 715, Астана 1 667, Шымкент 281, Караганда 244.
Уникальных профессий в URL: 2 238 — свободный текст, не справочник.

## 8. Что осталось непроверенным

- Сколько именно IT-вакансий: фильтр по специализации не подобран.
- Содержимое карточки вакансии — ни одна не открыта целиком.
- Работоспособность и полнота `sitemap/index.xml`, а это основной план обхода.
- Rate limit и поведение при частых запросах.
- Точные даты публикации вместо «сегодня/вчера».
- gross/net, формат работы, грейд, скиллы, признак архива.

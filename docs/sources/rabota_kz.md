## 1. Вердикт

**Рекомендация:** брать в Фазу 1

**Обоснование в одну строку:** единственная из проверенных площадок, где ToS прочитан целиком и запрета на автоматический сбор в нём нет, при этом карточки вакансий открыты в robots.txt, есть стабильный ID и зарплата примерно у трёх четвертей объявлений.

## 5. Правовая проверка — обязательно

| Вопрос | Ответ | Цитата / ссылка |
|---|---|---|
| `robots.txt` — что запрещает | `/auth`, `/fav`, `/note`, `/my`, а также пагинацию `/cv/*?after=`, `/cv/*&after=`, `/job/*?after=`, `/job/*&after=` | https://rabota.kz/robots.txt |
| ToS: запрещён ли автоматический сбор | **пункта о запрете не найдено** | https://rabota.kz/pages/terms |
| ToS: разрешено ли некоммерческое использование | явно не оговорено | — |
| ToS: разрешена ли публикация производных данных | явно не оговорено | — |
| Есть ли отдельные условия для API | API нет, условий нет | — |

**Дословная цитата ключевого пункта ToS:**

> Цитаты нет: в соглашении на https://rabota.kz/pages/terms пункты об автоматическом сборе, парсинге, роботах, «пауках» или копировании данных отсутствуют. Документ покрывает регистрацию, оплату, порядок оказания услуг и ответственность.

**Вывод:** можно собирать — с оговоркой, что карточки берём напрямую, а пагинацию `?after=` robots.txt запрещает, значит обход строим через `https://rabota.kz/sitemap/index.xml` (объявлен в robots.txt).

## 6. Качество данных

- [x] Стабильный ID вакансии — hex вида `6a9e98eb52c0ef00a510e001` в `/job/list/<id>`
- [x] Дата публикации — в виде «обновлено сегодня / вчера», точная дата не проверена
- [x] Название компании
- [x] Зарплатная вилка — примерно у 70–75%
- [x] Валюта — тенге
- [ ] Указание gross/net — не проверено
- [x] Город
- [ ] Формат работы (офис/удалёнка/гибрид) — не проверено
- [ ] Грейд явно указан — не проверено
- [ ] Скиллы отдельным полем — не проверено
- [ ] Полное описание — не проверено (карточку целиком не открывали)
- [ ] Признак «вакансия закрыта/архив» — не проверено

**Есть ли стабильный `source_id`:** да — hex-идентификатор из URL `/job/list/<id>`

**Пересечение с hh (на глаз):** не проверено

## 8. Что осталось непроверенным

- Сколько именно IT-вакансий: фильтр по специализации не подобран.
- Содержимое карточки вакансии — ни одна не открыта целиком.
- Работоспособность и полнота `sitemap/index.xml`, а это основной план обхода.
- Rate limit и поведение при частых запросах.
- Точные даты публикации вместо «сегодня/вчера».
- gross/net, формат работы, грейд, скиллы, признак архива.

## 5. Правовая проверка — обязательно

| Вопрос | Ответ | Цитата / ссылка |
|---|---|---|
| `robots.txt` — что запрещает | `/*.pdf$`, `/*/index.php/*`, **`/*/search/*`**, `/*/вакансии/*` и `/*/резюме/*` (в URL-кодировке), `/docs/*/node/*` | https://enbek.kz/robots.txt |
| ToS: запрещён ли автоматический сбор | **не проверено** | — |
| ToS: разрешено ли некоммерческое использование | не проверено | — |
| ToS: разрешена ли публикация производных данных | не проверено | — |
| Есть ли отдельные условия для API | API нет | — |

**Дословная цитата ключевого пункта robots.txt:**

> ```
> User-agent: *
> Disallow: /*/search/*
> Disallow: /*/%D0%B2%D0%B0%D0%BA%D0%B0%D0%BD%D1%81%D0%B8%D0%B8/*
> Disallow: /*/%D1%80%D0%B5%D0%B7%D1%8E%D0%BC%D0%B5/*
> ```
> (`%D0%B2%D0%B0%D0%BA%D0%B0%D0%BD%D1%81%D0%B8%D0%B8` = «вакансии», `%D1%80%D0%B5%D0%B7%D1%8E%D0%BC%D0%B5` = «резюме»)

**Вывод:** нужно уточнение.

Разбор: страница листинга `/ru/search/vacancy` подпадает под `Disallow: /*/search/*` — обходить её нельзя. Запреты `/*/вакансии/*` и `/*/резюме/*` относятся к кириллическим путям и на английский путь `/ru/vacancy/<slug>~<id>` **не распространяются**, то есть сами карточки не запрещены. Практический вывод: искать sitemap и строить обход по нему, а не по поиску. Пользовательское соглашение портала не читалось — до подключения прочитать обязательно.

**Тип:** HTML (Nuxt/Vue, SSR). Есть отдельный платный «официальный доступ для AI-агента».

| Вопрос | Ответ |
|---|---|

| Нужна регистрация приложения / токен? | Для официального агентского доступа — да: личный ключ либо вход в браузере, входит в платный тариф Hirify Plus |

| Работает ли без авторизации | HTML списков и карточек — да, обычный `curl`, HTTP 200, без капчи |
| Есть ли пагинация и её лимиты | Параметр `?page=` существует, но **закрыт в robots.txt** (`Disallow: /?page*`); лимиты не проверял |
| Есть ли полное описание в списке | не проверено |
| Есть ли фильтр по дате публикации | не проверено |

## 5. Правовая проверка — обязательно

| Вопрос | Ответ | Цитата / ссылка |
|---|---|---|
| `robots.txt` — что запрещает | `/telescope/*`, `/api/*`, `/dev/*`, `/dashboard/*`, `/admin/*`, `/auth/*`, `/?search*`, `/?sort_by*`, `/?page*`. Карточки `/jobs/...` не запрещены | https://hirify.me/robots.txt |
| ToS: запрещён ли автоматический сбор | Автоматизация как таковая разрешена — но **только** для поиска работы себе и только через официальный платный агентский доступ. Сбор каталога для стороннего продукта запрещён безусловно | п. 3.1-3.2 https://hirify.me/terms-of-service |
| ToS: разрешено ли некоммерческое использование | Исключения не предусмотрены: «Это правило не имеет исключений и не меняется вместе с тарифом» | п. 3.2 |
| ToS: разрешена ли публикация производных данных | Нет | п. 3.2 |
| Есть ли отдельные условия для API | Да — «Доступ для AI-агента», платный, в рамках Hirify Plus. Но запрет на сбор каталога действует и внутри него | п. 3.1-3.2 |

**Дословная цитата ключевого пункта ToS (п. 3.2 «Что запрещено»):**

> Обращаться к внутреннему API сайта в обход официального доступа: имитировать запросы веб-приложения, использовать cookie, сессии или токены авторизации для автоматических обращений. Внутренний API закрыт и не предоставляется для стороннего использования
>
> Собирать вакансии, названия компаний, ссылки для отклика и сведения об источниках, чтобы построить на них другой продукт: конкурирующий сервис, базу данных, бота, рассылку или агрегатор, а также перепродавать эти данные и передавать их третьим лицам. Запрет действует независимо от способа сбора, в том числе если данные получены через официальный доступ для AI-агента

И резюмирующая формулировка оттуда же:

> Если коротко: искать работу для себя можно как угодно, в том числе руками агента. Нельзя выносить из Hirify каталог - вакансии, компании, ссылки для отклика и источники - чтобы сделать из этого продукт. Это правило не имеет исключений и не меняется вместе с тарифом.

**Вывод:** нельзя

Формулировка написана максимально адресно и покрывает случай Talap буквально по словам («базу данных», «агрегатор», «независимо от способа сбора»). Платный агентский доступ **не** является лазейкой — запрет явно распространён и на него.

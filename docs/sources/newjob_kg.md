## 5. Правовая проверка — обязательно

| Вопрос | Ответ | Цитата / ссылка |
|---|---|---|
| `robots.txt` — что запрещает | админку, `/user/*`, `/search/`, `/taxonomy/*`, `/ajax/*`, `/resume/add`, `/vacancy/add`, вложенные `/vacancy/*/*` и `/resume/*/*`, а также **все URL с query-строкой** | https://newjob.kg/robots.txt |
| ToS: запрещён ли автоматический сбор | **не проверено** | — |
| ToS: разрешено ли некоммерческое использование | не проверено | — |
| ToS: разрешена ли публикация производных данных | не проверено | — |
| Есть ли отдельные условия для API | API нет | — |

**Дословная цитата ключевого пункта robots.txt:**

> ```
> Disallow: *?*
> Disallow: /vacancy/*/*
> Disallow: /vacancy/add
> Sitemap: https://newjob.kg/sitemap.xml
> ```

**Вывод:** нужно уточнение.

Разбор: карточка одного уровня `/vacancy/<code>` (например `/vacancy/mkpgvl`) **не запрещена** — под `Disallow: /vacancy/*/*` попадают только пути на сегмент глубже. Но `Disallow: *?*` закрывает любую пагинацию и фильтрацию через query-строку, поэтому обход нужно строить по объявленному `sitemap.xml`. Пользовательское соглашение не читалось — до подключения обязательно.

## 6. Качество данных

- [x] Стабильный ID вакансии — буквенно-цифровой код в `/vacancy/<code>`, напр. `mkpgvl`, `ptx8qz`
- [x] Дата публикации — есть, вид «сегодня»; точный формат не проверен
- [x] Название компании
- [x] Зарплатная вилка — есть, доля не оценена
- [x] Валюта — сом
- [ ] Указание gross/net — не проверено
- [x] Город
- [ ] Формат работы (офис/удалёнка/гибрид) — не проверено
- [ ] Грейд явно указан — не проверено
- [ ] Скиллы отдельным полем — не проверено
- [ ] Полное описание — не проверено
- [ ] Признак «вакансия закрыта/архив» — не проверено

**Есть ли стабильный `source_id`:** да — код из URL `/vacancy/<code>`

**Пересечение с hh (на глаз):** вероятно низкое — hh в Кыргызстане слабо представлен, но **не проверено**

## 8. Что осталось непроверенным

- Пользовательское соглашение — не читалось. Блокирующий пункт.
- Доля вакансий с зарплатой в IT-рубрике — цифры нет, только факт наличия поля.
- Существует ли и насколько полон `sitemap.xml` — от него зависит весь обход, раз query-строки запрещены.
- Содержимое карточки: gross/net, формат работы, грейд, скиллы, признак архива, точная дата.
- Стабильность кода вакансии во времени (не переиспользуется ли).
- Не перепроверены конкуренты: job.kg (DNS не резолвится — возможно, временно) и employment.kg (таймаут). Если job.kg поднимется, он по поисковой выдаче крупнее.

# Талап — приложение

Внутренняя версия сайта: рентген вакансии, профессии, компании, навыки,
калькулятор, конструктор срезов, машина времени, сравнение, карта, сюжеты.

> **НЕ ПУБЛИКОВАТЬ.** Приложение работает на данных по отдельным вакансиям
> и компаниям. Условия API hh (пп. 3.11, 4.3, 4.6) запрещают передавать такие
> данные третьим лицам. Публикация — после разрешения hh.
> Подробно: [docs/sources/hh.md](../docs/sources/hh.md) §5, план — [docs/site-plan.md](../docs/site-plan.md).

## Запуск

```bash
# 1. данные: выгрузить на сервере и забрать в web/public/data
TALAP_SERVER=user@host bash scripts/sync_app_data.sh

# 2. приложение
cd web && npm install && npm run dev      # http://127.0.0.1:5180
```

Адрес сервера в репозитории не хранится — он публичный. Можно положить
`TALAP_SERVER=...` в локальный `.env` в корне проекта.

## Где что

| | |
|---|---|
| `src/model/store.ts` | загрузка данных, индексы, оценка зарплаты по похожим |
| `src/model/derive.ts` | срезы: события, спрос по неделям, навыки и надбавки, срок жизни |
| `src/model/stats.ts` | квантили (тот же метод, что в Python), Каплан — Мейер |
| `src/charts/kit.tsx` | графики: столбики, ряды, распределения, кривая выживания |
| `src/pages/` | страницы |
| `src/ctx.tsx` | контексты данных и страны — отдельно от App.tsx ради горячей перезагрузки |

Данные готовит Python: [`scripts/export_app_data.py`](../scripts/export_app_data.py)
(факты: вакансии, присутствие по дням, события, телеграм) и
[`scripts/export_site_data.py`](../scripts/export_site_data.py) (агрегаты обзора).
Браузер только фильтрует и рисует — так срезы на разных страницах не расходятся.

## Осторожно

- **`npm run build` кладёт данные в `dist/`.** Vite копирует `public/` целиком,
  включая `public/data/`. Папка `dist/` в `.gitignore`, но выложить её на
  хостинг — значит опубликовать данные по вакансиям.
- **Карта ходит на tile.openstreetmap.org.** Для внутреннего использования
  можно, для публичного сайта — нет: правила OSM запрещают заметный трафик.
  Перед публикацией — собственные тайлы (Protomaps, PMTiles).
- **Папка кода — `src/model`, не `src/data`.** Корневой `.gitignore`
  игнорирует любые каталоги `data/`.

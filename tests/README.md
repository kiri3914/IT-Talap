# Тесты

```bash
.venv/bin/pip install -e ".[dev]"
.venv/bin/python -m pytest tests/ -q
```

## Что покрыто

Чистые функции разбора — то, где уже трижды находились **тихие** ошибки:
код не падал, а просто давал неверный результат.

| Файл | Что проверяет |
|---|---|
| `test_telegram_fields.py` | разбор постов: шаблоны каналов, зарплаты, gross/net |
| `test_telegram_parse.py` | разбор HTML превью: посты, просмотры, сущности |
| `test_grade.py` | распознавание грейда из заголовка, описания и стажа |
| `test_currency.py` | разбор ответов трёх нацбанков, включая номинал и windows-1251 |

## Правило

**Каждый найденный баг закрепляется тестом.** Уже закреплены:

- число без валюты (`Оплата: 800000`) — давало 42% вместо 83%
- разделители разрядов (`800,000 тенге`, `100.000 тенге`)
- страна из справочника каналов, а не из поля вызывающего кода
- хештеги оттуда же — **найден самим тестом при написании**
- `lead` важнее `senior` у «Senior Team Lead»

Последний пункт показателен: тест нашёл ту же ошибку в другом поле,
которую я чинил накануне. Зависимость от полей, проставляемых снаружи, —
системная проблема, а не разовая опечатка.

## Чего нет намеренно

Сетевых вызовов. Тесты не ходят в hh, телеграм и нацбанки: ответы
подставляются через `httpx.MockTransport`. Проверка живых источников —
задача `scripts/probe_*.py` и `verify_coverage.py`, и она осознанно
отделена от тестов.

# Talap

**Аналитика рынка IT-труда Казахстана и Центральной Азии.**

Не агрегатор вакансий. Ежедневные снимки состояния рынка, из которых
считаются метрики, недоступные при взгляде на текущий срез: время
присутствия вакансии в выдаче, частота перепубликаций, динамика вилок,
устаревание технологий.

Данные для такого наблюдения есть у площадок, но они их не публикуют.
Talap делает их публичными и проверяемыми.

## Архитектура

```
ИСТОЧНИКИ  hh API ✅  ·  Telegram ✅  ·  hirehi ⬜
     │  Python: httpx + backoff
     │  fetch → write_raw → validate → alert
     ▼
RAW  MinIO / S3          ✅   неизменяемое сырьё, пишется ДО валидации
     ▼  dbt
STAGING  PostgreSQL      ⬜   типизация, нормализация, вырезание контактов
     ▼  dbt
CORE  PostgreSQL         ⬜   SCD2, снапшоты, справочники, дедупликация
     ▼  dbt
MARTS  Postgres → ClickHouse ⬜
     ▼
Metabase ⬜  →  DRF + React ⬜

Оркестрация: cron ✅ → Airflow ⬜        Алерты: Telegram ✅
```

Ключевое правило: **сырьё пишется до валидации.** Падение проверки схемы
не должно стоить дня истории — его нельзя собрать заново.

## Быстрый старт

```bash
git clone git@github.com:kiri3914/IT-Talap.git && cd IT-Talap
python3 -m venv .venv && .venv/bin/pip install -e .
cp .env.example .env && nano .env      # credentials
docker compose up -d                   # MinIO
.venv/bin/python scripts/init_bucket.py
bash scripts/check_env.sh
.venv/bin/python -m ingestion.run --country kz --skip-details
```

Развёртывание на сервере — [docs/deploy.md](docs/deploy.md).

## Правила проекта

**Новая технология — только через ADR** с ответом на вопрос «что сломается,
если её убрать». Пет-проекты чаще умирают от переусложнения стека,
чем от скучных инструментов.

**Замерь, прежде чем усложнять.** Не переходить к эмбеддингам, пока
не измерено, сколько не покрыл точный хеш. Не звать LLM, пока не измерено,
сколько не покрыли регулярки.

**Сбор важнее фич.** Выбор между «починить пайплайн» и «сделать витрину» —
всегда пайплайн. Необработанные данные обработаются завтра, несобранные
не соберутся никогда.

**Ни один источник не подключается**, пока в его файле в `docs/sources/`
не записан дословный пункт ToS про автоматический сбор.

## Что мы честно не можем

| Не можем | Почему |
|---|---|
| Показать реальную зарплату нанятого | публично недоступна нигде |
| Показать количество откликов | не публикует ни одна площадка |
| Утверждать, что вакансия закрылась наймом | видим только исчезновение из выдачи |
| Покрыть вакансии без вилки | их 62% |
| Дать статистику по малым городам | ниже порога в 5 наблюдений |

**Мы меряем не «сколько платят», а «сколько предлагают».**

## Правовое

Собираются только публично опубликованные данные вакансий. Персональные
данные соискателей не собираются, контакты вырезаются на staging.
Публикуются агрегаты со ссылкой на первоисточник, полные чужие тексты
не воспроизводятся. Соблюдаются rate limits и `robots.txt`.

Источники с прямым запретом автоматического сбора в ToS не подключаются:
getmatch, hirify, ishkop.uz, LinkedIn.
